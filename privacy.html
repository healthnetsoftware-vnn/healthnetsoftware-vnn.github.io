Privacy Policy / Chính sách bảo mật

Last updated / Cập nhật: 26/10/2026

1. What data the app accesses

AutoBackupDB uses Google OAuth with the https://www.googleapis.com/auth/drive.file scope only. It can create, read and delete only the files and folders it created itself in the user's Google Drive (the folder Backup_SQL_Server). It cannot see any other files in the user's Drive. The app also reads the signed-in account's email address to display which account is connected.

2. How data is used

The data is used solely to upload the user's own database backup files to the user's own Google Drive and to remove old backup files created by the app.

3. Storage and sharing

The app runs entirely on the user's computer. No data is sent to the developer or to any third-party server. OAuth tokens and settings are stored locally on the user's computer (Windows user profile). We do not sell, share or transfer Google user data to anyone.

4. Revoking access

Users can sign out in the app at any time, or revoke access at https://myaccount.google.com/permissions.

5. Google API Services User Data Policy

AutoBackupDB's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
