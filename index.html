AutoBackupDB

AutoBackupDB is a Windows desktop tool that automatically backs up SQL Server databases on a schedule, compresses the backup files and uploads them to the user's own Google Drive.

AutoBackupDB là công cụ Windows tự động sao lưu database SQL Server theo lịch, nén file backup và tải lên Google Drive của chính người dùng.

Features / Tính năng

  • Scheduled SQL Server backups (daily, weekly, bi-weekly) / Sao lưu theo lịch (hằng ngày, 1 tuần, 2 tuần)
  • ZIP compression / Nén file ZIP
  • Upload to the user's Google Drive and clean up old backups / Upload lên Google Drive và dọn bản backup cũ

Google data usage / Sử dụng dữ liệu Google

The app only requests the drive.file scope, so it can only see and manage files it created itself. See the Privacy Policy.

Ứng dụng chỉ xin quyền drive.file: chỉ thấy và quản lý file do chính ứng dụng tạo ra. Xem Chính sách bảo mật.
